SETUPEGIP V14 — RENDER WEB SERVICE

POR QUE ESTA VERSÃO
A V13 publicada como Static Site consegue WebSocket ao vivo, mas /api/kline não existe em site estático.
A V14 inclui um servidor Node.js/Express que:
- entrega o app PWA;
- cria /api/kline;
- consulta o histórico na API de contratos da MEXC;
- mantém o WebSocket direto no navegador.

COMO PUBLICAR
1. No GitHub, substitua o conteúdo do repositório Oil_Mexc por ESTA estrutura:
   server.js
   package.json
   public/
      index.html
      manifest.json
      service-worker.js
      icon-192.png
      icon-512.png

2. No Render, NÃO use Static Site para a V14.
   Crie: New + > Web Service

3. Conecte o mesmo repositório Oil_Mexc.

4. Configure:
   Name: oil-mexc
   Branch: main
   Root Directory: vazio
   Runtime: Node
   Build Command: npm install
   Start Command: npm start

5. Deploy.

6. Teste:
   https://SEU-ENDERE.onrender.com/api/health
   Deve retornar JSON com ok:true.

7. Abra o app e toque Conectar / Atualizar.
   O esperado é Histórico: carregado (...) em vez de histórico bloqueado.

IMPORTANTE
Se quiser preservar o Static Site atual enquanto testa, crie o Web Service com outro nome,
por exemplo: oil-mexc-v14. Depois que funcionar, você decide qual URL manter instalada.
